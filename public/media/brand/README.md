# Logo oficial XDAW

Coloca aquí el archivo **xdaw-logo.webp** (nombre exacto, en minúsculas).

Ruta en el repositorio: `public/media/brand/xdaw-logo.webp`.
Se recomienda WebP con fondo transparente, versión clara para fondo carbón y al menos 1600 px de ancho, recortado sin márgenes transparentes excesivos.

El mismo archivo se usa en Hero, cabecera y footer, sin deformarlo ni recortarlo. Hasta incorporarlo se conserva el logotipo tipográfico. Ejecuta `npm run build` después de agregarlo; el build lo publica en `media/brand/xdaw-logo.webp`, compatible con /xdaw/.
