# Imágenes de Vive XDAW

Coloca en esta carpeta los archivos WebP con estos nombres exactos:

- `encuentra-tu-ritual.webp`: card principal de clases.
- `xdaw-kids.webp`: card de XDAW Kids.
- `la-vibracion-del-grupo.webp`: card de comunidad.

Usa imágenes sin textos ni logos incorporados. Mantén los protagonistas cerca del centro y deja espacio tranquilo en la parte inferior para los títulos, descripciones y enlaces. El encuadre se adapta entre desktop y móvil.

Ubicación en el repositorio: `public/media/vive-xdaw/`.
El build copia esta carpeta a `media/vive-xdaw/`, compatible con GitHub Pages bajo `/xdaw/`.

Esta carpeta prepara la entrega de assets. Las fotografías se conectarán con las cards cuando estén incorporadas.
