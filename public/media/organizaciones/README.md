# Imagen de Organizaciones

Coloca aquí el archivo `lleva-xdaw-a-tu-organizacion.webp` (nombre exacto, en minúsculas y sin tildes).

Ubicación en el repositorio: `public/media/organizaciones/lleva-xdaw-a-tu-organizacion.webp`.

Usa una imagen horizontal WebP sin textos ni logos incorporados. Mantén a las personas cerca del centro para permitir el recorte adaptable en escritorio y móvil.

El build copia esta carpeta a `media/organizaciones/`, compatible con GitHub Pages bajo `/xdaw/`. La imagen se conectará con el bloque de Organizaciones cuando esté incorporada.
