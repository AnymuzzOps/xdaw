# Fotografías de los mundos XDAW

Coloca en esta carpeta los tres archivos originales con estos nombres exactos:

- `xdaw-dance.webp`
- `xdaw-exotic.webp`
- `xdaw-workout.webp`

Resolución recomendada: 1600 × 2000 px (vertical 4:5). Formato WebP, idealmente entre 150 y 350 KB por archivo. Sin textos ni logos incorporados. Mantén al protagonista cerca del centro y deja el tercio inferior despejado para el contenido de la card; el encuadre se adapta a móvil y escritorio.

Ubicación en el repositorio: `public/media/worlds/`.
El build copia estos archivos a `media/worlds/` para GitHub Pages bajo `/xdaw/`.

Esta carpeta prepara la entrega de assets. La conexión de las fotografías con las cards se realizará al incorporarlas.
